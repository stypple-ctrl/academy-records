## 1. 목적
기능과 업무 흐름은 그대로 두고, 화면을 노션처럼 **조용하고 문서처럼 읽히게** 바꾼다. 노션식 조작도 몇 가지 넣는다.

## 2. 범위

### 7-1 · 겉모습 (색·글꼴·모양)
| 지금 (Apple HIG) | 바꾼 뒤 (노션) |
|---|---|
| 회색 배경 위에 흰 카드, 그림자 | 흰 바탕, 카드는 얇은 테두리만 |
| 둥근 캡슐 버튼, 파란 선택 | 모서리 4~6px 사각 버튼, 메뉴 선택은 옅은 회색 |
| 파랑·초록·주황·빨강 배지 | 노션 태그 색 (회색·갈색·주황·노랑·초록·파랑·보라·분홍·빨강, 옅은 바탕 + 진한 글자) |
| 글자 검정 | 노션 글자색 (따뜻한 진회색), 다크는 노션 다크 (#191919 바탕) |

### 7-2 · 배치
- **왼쪽 사이드바:** 맨 위에 학원 이름과 역할, 그 아래 "검색", 그 아래 메뉴.
- **위쪽 줄:** 경로 표시(예: "원장 / 원장 대시보드"), 오른쪽에 날짜와 역할 바꾸기.
- **페이지 머리:** 큰 아이콘 + 큰 제목. 노션 페이지처럼 보이게.
- **안내 상자:** 체험 안내 같은 상자는 노션 콜아웃(아이콘 + 옅은 바탕)으로.

### 7-3 · 노션식 조작
| 조작 | 내용 |
|---|---|
| 빠른 찾기 | 사이드바 "검색" 또는 ⌘K/Ctrl+K → 학생 이름·학교·반으로 찾기 → Enter로 타임라인. 조교는 학생 이력을 볼 수 없으므로 없음. 담임은 내 학생만 |
| 토글 블록 | 카드 제목 왼쪽 ▸ 를 누르면 접기/펴기. 같은 화면에 다시 와도 유지 |
| 표/보드 보기 | 원장 브리핑 "퇴원 위험"에서 [표 / 보드] 전환. 보드는 처리 상태(새로·담임 확인 요청·챙기는 중·학부모 연락함·해결)별 칸 |
| 사이드바 접기 | « 로 사이드바를 숨기고, ☰ 로 다시 열기 |

### 제외
새 업무 기능, 데이터 규칙, 결정 대기 항목, 실제 프로그램 전환. 학부모 리포트 화면은 학부모가 휴대폰으로 보는 화면이라 색만 맞춤.

## 3. 완료 기준
- 자동 점검: **`SELFTEST PASS 110` + 이번 점검 전부 통과** (라이트·다크)
  - 빠른 찾기: 이름으로 찾으면 그 학생이 나오고, 담임에게는 다른 반 학생이 안 나오고, 조교에게는 검색이 없음
  - 토글 블록: 접으면 내용이 숨고, 다시 그려도 접힌 채
  - 보드 보기: 보드의 학생 수 = 표의 학생 수, 상태별 칸에 맞게 들어감
  - 사이드바 접기/열기
- 글자 대비 4.5 이상(라이트·다크), 누르는 것은 모두 키보드로
- 휴대폰(375px)·넓은 화면(1440px)에서 가로 넘침 0
- 기존 흐름(조교 입력 → 담임 확정 → 조교 처리 → 원장 → 원어민) 정상, 전 메뉴 오류 0건

### 원장 체험 확인
- [ ] 화면이 노션처럼 흰 바탕·얇은 선·회색 메뉴로 보인다
- [ ] ⌘K(윈도우는 Ctrl+K)를 누르고 학생 이름을 치면 바로 그 학생으로 간다
- [ ] 카드 제목 옆 ▸ 로 접고 펼 수 있다
- [ ] 원장 브리핑 "퇴원 위험"을 [보드]로 바꾸면 처리 상태별로 나뉜다
