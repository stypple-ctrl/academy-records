# 작업계약서 · 5단계 「화면 재구성 남은 것」

| 항목 | 내용 |
|---|---|
| 대상 파일 | `index.html` |
| 근거 | 작업 계획서 Task 10·11·12 중 아직 없는 것 + 재점검 (2026-10-08) |
| 선행 조건 | 4단계 완료 (`SELFTEST PASS 71`, GitHub 업로드) |
| 승인 | 의뢰인 사전 승인 ("작업계약서에 따라 남은작업 순차진행", 2026-10-08) |

## 1. 재점검 결과: 이미 된 것
UI/UX 개편과 역할별 새 방향에서 먼저 만든 것 — 경과 시간, 모두 입장, 20·40분 "지금" 표시, 결과 입력 대기 분리·한 번에 입력, 원장 "지금 챙길 일", 숫자 카드 → 상세 목록, 위험 학생 처리 상태·담임 확인 요청.
**빼는 것:** 계획의 "짧은 태그(20자)" — 지금은 한 줄 말줄임 + 마우스를 올리면 전체 문장으로 같은 효과라 만들지 않음.

## 2. 범위 (남은 것만)
| 번호 | 작업 | 내용 |
|---|---|---|
| 5-1 | 셔틀 시간 | 학생마다 셔틀 시간(또는 도보). 조교 카드 머리에 "셔틀 17:50"(2시간 안이면 "N분 남음"), 카드를 **셔틀 이른 순**으로, 도보는 맨 뒤 |
| 5-2 | 담임 확정 대기 목록 | 조교 강당 화면 아래에 아직 담임이 확정하지 않은 나머지 제안 (이름·과제만, 읽기 전용). 학생이 먼저 와도 조교가 알 수 있게 |
| 5-3 | 교사 "오늘 메모" | 내 반 홈 맨 위에 한 줄 메모(학생 선택 가능, 쉬는 시간용). 목록에서 [케어 기록으로 정리] → 케어 기록 창에 내용이 채워지고, 저장하면 메모 삭제. [지우기]도 가능 |

### 제외
결정 대기 항목, DB 단계, 발견 목록의 작은 문제.

## 3. 완료 기준

### 자동 점검: `SELFTEST PASS 76` (71 + 5)
| 점검 | 내용 |
|---|---|
| 경과 분 | 17:05 → 17:31 = 26분 |
| 일괄 입장 | 대기 학생 전원 입장 시각 기록, 이미 입장한 학생은 그대로 |
| 셔틀 순 정렬 | 조교 카드의 셔틀 시간이 이른 순, 도보는 뒤 |
| 확정 대기 학생 보임 | 확정 대기 제안이 있으면 조교 화면에 "담임 확정 대기" |
| 메모 → 케어 정리 | 메모로 케어 기록을 저장하면 메모가 사라지고 내용이 기록에 들어감 |

### 기존 기능 유지
전체 흐름(조교 입력 → 담임 확정 → 조교 처리 → 원장 → 원어민), 전 메뉴 오류 0건, 휴대폰 폭 가로 넘침 없음.

### 원장 체험 확인
- [ ] 조교 강당 화면 카드에 셔틀 시간이 보이고 이른 순서다
- [ ] 담임이 확정하기 전에 조교 화면에 "담임 확정 대기" 학생이 보인다
- [ ] 담임 홈에서 메모를 남기고 [케어 기록으로 정리]하면 메모가 사라진다
