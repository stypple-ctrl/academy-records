| 항목 | 내용 |
|---|---|
| 대상 파일 | `index.html`, 새 파일 `api/school.js`(버셀 서버 함수), `.vercelignore`, `tests/api-school.test.mjs`, README |
| 근거 | 의뢰인 요청 "NEIS 키로 학사일정, 학교알리미 키로 학생 수·학급 현황" (2026-10-08) |
| 지역 | 경기도 안산시 단원구 (학교알리미 시도 41 · 시군구 41273, NEIS 경기도교육청 J10) |
| 선행 조건 | 7단계 완료 (`SELFTEST PASS 115`), 버셀 Production에 `NEIS_KEY`·`SCHOOLINFO_KEY` 등록 |
| 진행 | 작업 → 별도 검토 → GitHub → 실제 키로 확인하려고 버셀 배포(원장 승인 후) |

## 1. 목적
학생의 학교를 누르면 그 학교의 다가오는 시험·행사 일정과 학생 수·학급 현황을 본다. 원장 대시보드에는 다가오는 학교 시험을 모아 보여 준다.

## 2. 범위
| 번호 | 작업 | 내용 |
|---|---|---|
| 8-1 | 실제 학교 연결 | 데모의 가짜 학교 5곳을 단원구 실제 학교로 바꿈: 고잔초·와동초·선부초·단원중·와동중 |
| 8-2 | 서버 함수 `api/school.js` | 키는 버셀 환경 변수에서만 읽음. 정해 둔 학교 목록만 조회(다른 학교 요청은 거절). NEIS 학사일정(오늘부터 120일) + 학교알리미 조사항목 09(학년별·학급별 학생 수). 응답은 버셀이 6시간 저장해 두고 재사용(호출 횟수 절약). 오류가 나도 키나 내부 주소는 응답에 넣지 않음 |
| 8-3 | 학교 창 | 학생 목록·타임라인·위험 학생 표에서 학교 이름을 누르면 창: 학생 수·학급 수·학년별 표, 다가오는 일정(시험은 강조 + D-day), 우리 학원 이 학교 학생 수 |
| 8-4 | 원장 "다가오는 학교 시험" | 아침 브리핑에 카드: 45일 안의 시험만, 학교·시험명·날짜·D-day·우리 학생 수 |
| 8-5 | 실패해도 안전 | 내 컴퓨터에서 파일로 열면 "배포 주소에서만 불러옵니다". 불러오기 실패 시 "불러오지 못했어요 · 다시 시도". 나머지 화면은 그대로 |

### 제외
학교별 시험 범위·시간표·급식, 실제 학생 데이터, 학교 목록 관리 화면(학교 추가는 다음 단계).

## 3. 완료 기준
- 자동 점검(라이트·다크) `SELFTEST PASS 115` + 이번 점검 통과
  - 학교 창: 시험 강조·D-day·학생 수 표시, 연결 안 된 학교는 링크 아님, 파일로 열면 안내 문구
  - 대시보드 카드: 45일 안 시험만, 우리 학생 수
- 서버 함수 점검(`node tests/api-school.test.mjs`): 응답 정리, 목록 밖 학교 거절, 키가 응답에 안 나옴
- 키는 GitHub·화면 파일 어디에도 없음 (`git grep`으로 확인)
- 배포 후 실제 키로 5개 학교 모두 일정·학생 수가 나옴

### 원장 체험 확인
- [ ] 학생 목록에서 "단원중"을 누르면 단원중 시험 일정과 학생 수가 나온다
- [ ] 원장 아침 브리핑에 "다가오는 학교 시험" 카드가 있다

## 4. 안전장치
- 키는 버셀 Secret 환경 변수에만. 채팅·코드·로그에 출력하지 않음.
- 서버 함수는 정해 둔 학교만 조회하므로 다른 사람이 주소로 키를 마음대로 쓸 수 없음.
- 배포는 원장 승인 후. 되돌림 지점: 8단계 시작 커밋 `a61f4db`.
