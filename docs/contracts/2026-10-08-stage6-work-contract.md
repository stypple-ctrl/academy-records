# 작업계약서 · 6단계 「작은 문제 정리」

| 항목 | 내용 |
|---|---|
| 대상 파일 | `index.html` (+ README 발견 목록 갱신) |
| 근거 | README "아직 고치지 않은 작은 문제" 20줄(약 30건) + 새로 설치한 스킬 점검 |
| 쓰는 스킬 | `impeccable` audit(접근성·반응형) · harden(예외 상황) · clarify(문구), `break-ui`(최악의 데이터) |
| 선행 조건 | 1~5단계 완료 (`SELFTEST PASS 78`, GitHub 업로드) |
| 승인 | 의뢰인 승인 ("계약서 만들고 시작", 2026-10-08) |
| 진행 | 6-1 → 6-2 → 6-3 → 6-4 순서, 묶음마다 점검·저장 → 끝나고 별도 검토 → GitHub |

## 1. 목적
실제 시범 운영 전에, 쓰다가 헷갈리거나 잘못 보이는 작은 문제를 한 번에 정리한다. 새 기능은 만들지 않는다.

## 2. 범위

### 6-1 · 접근성·화면 (impeccable audit)
| 문제 | 고치는 방법 |
|---|---|
| 아바타 흰 글자 대비 부족 | 배경을 더 진하게 (흰 글자 대비 4.5 이상) |
| 채움 위 채움 글자 대비, 일부 빨강 글자 대비 | 안쪽 칸 배경을 카드색으로, 빨강 글자는 진한 빨강(`--r-ink`)으로 |
| 할 일 목록·숫자 카드·토글이 키보드로 안 됨 | 버튼처럼 Tab으로 이동·Enter로 실행, 토글도 키보드로 켜고 끄기 |
| 확인함 버튼이 아이콘만 있음 | 보이는 글자 "확인함" + 누르는 영역 넓히기 |
| 좁은 화면 위험 학생 표 이름 세로 줄바꿈, 휴대폰 숫자 카드 글자 줄바꿈 | 이름 칸 줄바꿈 금지·최소 폭, 숫자 줄바꿈 금지 |
| 부정 표현 경고가 나타나며 버튼이 밀림 | 경고 자리를 미리 확보 |

### 6-2 · 예외 상황 (impeccable harden)
| 문제 | 고치는 방법 |
|---|---|
| 점수 칸에 31 → 화면 31, 저장 30 | 칸을 벗어나면 보정된 값으로 바로 표시 |
| 확인할 기록이 없는 교사의 결과 입력률 100% | "–"로 표시 |
| "숨긴 항목 N개"에 케어 저장으로 빠진 항목까지 셈 | 실제로 숨겨진 항목만 셈 |
| 미달 2회 연속 신호에 기간 제한 없음 | 최근 4주 안의 점수만 |
| 역할 바꿔 들어오면 조교에게 '오늘 수업 없는 반' 안내 | 역할 바꿀 때 선택했던 반 초기화 |
| 되돌리기가 같은 날 다른 조교 기록까지 지움 | 내가 입력한 기록만 되돌림 |
| 이미 취소된 티켓 다시 취소 가능 | 막음 |
| 결석 처리한 날의 이월 과제 기록 일부 남음 (데모 데이터) | 생성 데이터 정리 |
| 자주 틀리는 단어에 우연한 단어가 섞임 | 나온 횟수 대비 틀린 비율 40% 이상만 |
| "지금" 체크 알림이 필요 없는 학생에게도 깜빡임, 자정 넘으면 경과 0 | 저장 규칙과 같은 조건, 자정 넘김 계산 |
| 이미 출발한 셔틀이 빨간 배지, 같은 셔틀 시간 순서 바뀜 | 회색 "셔틀 출발함", 순서 고정 |
| 케어 기록 창에서 학생·확인일·리포트 후보만 바꾸면 닫을 때 경고 없음 | 바뀐 것으로 판단 |
| 메모 지우기 확인창 없음 | 확인창 |
| 화면을 처음 열 때 코멘트가 만들어져 그 뒤 케어 기록이 기본 선택에서 빠짐 | 승인 전에는 새 후보를 기본 선택에 추가 |

### 6-3 · 문구·정보 (impeccable clarify)
| 문제 | 고치는 방법 |
|---|---|
| 상담 대화 예시 "집에서는 …" 문장 2종 어색 | 결석·보충 학습 부탁은 "집에서는" 빼기 |
| 학부모 리포트 "+0.0점 올랐어요" | "지난달과 같아요" |
| 이번 달 점수 없는 학생 "평균 –점" | "이번 달 단어 시험 기록이 아직 없어요" |
| 안내 문구 조사 "A은" | 문장 바꿔 조사 없이 |
| '챙기기 기록'이 학부모 연락으로 미리 채워짐 | 조치는 담임이 고르게 비워 둠 |
| 대시보드에서 교사별 미입력·공백 수, 케어 유형 분포가 빠짐 | 성적·기록 탭에 다시 표시 |
| 당부 메모가 지워지지 않음, 관찰 태그 지우기 불가 | 당부 [지우기], 같은 관찰 태그 다시 누르면 해제 |

### 6-4 · 최악의 데이터 (break-ui)
긴 이름(예: "남궁아름다운나라"), 영문 긴 이름, 0건, 아주 긴 과제명·메모, 이모지 등을 넣어 **원장 브리핑·교사 홈·조교 카드·학부모 리포트**를 깨 본다.
- 화면이 넘치거나 겹치는 것만 이번에 고침.
- 그 외 발견은 고치지 않고 발견 목록에 기록.

### 제외
새 기능, 결정 대기 항목, 실제 프로그램 전환, 데모 데이터 규칙(가중치 등) 변경.

## 3. 완료 기준
- 자동 점검: **`SELFTEST PASS 78` + 이번 점검 전부 통과** (항목마다 점검 1개 이상, 문구·화면 항목은 렌더 결과로 확인)
- 글자 대비: 아바타·빨강 글자·채움 위 글자 4.5 이상 (라이트·다크)
- 키보드: 할 일 목록·숫자 카드·토글이 Tab으로 이동되고 Enter/Space로 동작
- 휴대폰(375px)·좁은 화면(750px)·넓은 화면(1440px): 주요 화면 가로 넘침 0
- 최악의 데이터로 4개 화면을 렌더했을 때 넘침·겹침 0
- 기존 흐름(조교 입력 → 담임 확정 → 조교 처리 → 원장 → 원어민) 정상, 전 메뉴 오류 0건
- README 발견 목록에서 고친 항목 삭제, 새로 발견한 것은 추가

### 원장 체험 확인
- [ ] 키보드 Tab만으로 원장 "지금 챙길 일"을 골라 들어갈 수 있다
- [ ] 점수 칸에 31을 넣고 다른 칸을 누르면 30으로 바뀐다
- [ ] 학부모 리포트에 "+0.0점 올랐어요"가 더 이상 나오지 않는다
- [ ] 아주 긴 이름의 학생도 카드·표가 깨지지 않는다

## 4. 안전장치 · 중단 조건 · 보고
- 1~5단계와 같음. GitHub 업로드는 자동 점검 통과 때만 됨(pre-push 점검).
- 작업 중 발견한 새 문제는 계약 범위가 아니면 고치지 않고 기록.
- 되돌림 지점: 6단계 시작 커밋.
