## 1. 목적
같은 학생을 두고 화면마다 다른 판단이 나오지 않게 하고, 조교가 볼 수 없어야 할 지난 점수를 막는다.

## 2. 범위

### 포함
| 번호 | 작업 | 내용 |
|---|---|---|
| 3-1 | 통과 판정 통일 | 저장된 통과 여부(`passed`) 대신 **현재 기준값**으로 매번 판정 (`isPassScore`). 대시보드 통과율, 타임라인 배지·그래프, 상담 그래프, 월말 리포트 통과 횟수 6곳 |
| 3-2 | 판단 규칙 공유 | 담임 "오늘 챙길 학생"의 **급락**·**미달 2회 연속** 계산을 함수(`wordDrop`, `fail2Of`)로 분리하고, 퇴원 위험 점수(`churnOf`)도 같은 함수를 사용 (각 10점). 원장 브리핑·타임라인·담임 화면이 같은 신호를 보여줌 |
| 3-3 | 조교 입력 제한 | 조교는 **오늘 수업이 있는 반만** 선택 가능 (`entryClasses`). 오늘 수업이 없는 반에 들어오면 표 대신 안내 |

### 재점검으로 바뀐 점
- 계획의 `signalsOf`(위험/주의 2단계)는 만들지 않음. 그 뒤 생긴 **퇴원 위험 점수**가 같은 역할을 하므로, 신호를 그쪽으로 합침.
- 원장 "위험 학생" 탭(PRD 5-4 기준)은 그대로 둠 — PRD에 정해진 별도 기준이라서.

### 제외
4·5단계 작업, 결정 대기 항목, DB 단계, 발견 목록의 작은 문제.

## 3. 완료 기준

### 자동 점검: `SELFTEST PASS 61` (57 + 4)
| 점검 | 내용 |
|---|---|
| 급락 학생은 퇴원 위험에도 신호 | 급락 패턴 학생의 `churnOf` 신호에 "급락"이 있고, 담임 화면 하락률과 같은 숫자 |
| 기준 변경 즉시 반영 | 통과 기준 26으로 바꾸면 25점이 모든 화면에서 미달 |
| 조교는 오늘 수업 반만 | 조교 반 목록이 전부 오늘 수업 반 |
| 조교 지난 점수 못 봄 | 조교가 오늘 수업 없는 반으로 가면 점수 칸이 없음 |

### 기존 기능 유지
1단계 회귀 6가지 + 조교 채점 + 원장 브리핑 + 상담 준비, 전 메뉴 오류 0건.

### 원장 체험 확인
- [ ] 관리·설정에서 통과 기준을 26으로 바꾸면 타임라인 25점이 "미달"로 바뀐다
- [ ] 급락한 학생(예: 강서연)이 원장 브리핑·타임라인·담임 화면에 모두 "급락"으로 보인다
- [ ] 조교 점수 입력의 반 목록에 오늘(목) 수업 반만 있다
